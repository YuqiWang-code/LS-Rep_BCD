## 4. Gate R2 最终判定：**失败（0/4 域通过）**

预注册 Gate R2（`train_scripts/CATA-CD/Run2/README.md` 顶部）：

> S-PCG-S2 同协议**在四域**优于 S1；重点看 SYSU、LEVIR、WHU，**CDD 不降**；
> 部署 <5M、swap/deploy <1e−6。未达则拒绝该 gate 假设，不新增第四专家。

| 数据集 | S2−S1 ΔF1 | ΔIoU | τ | 判定 |
|---|---:|---:|---:|---|
| SYSU | +0.9674 | +1.4097 | 1.353 | **FAIL** |
| WHU | +0.0154 | +0.0271 | 1.587 | **FAIL** |
| LEVIR | +0.3899 | +0.6569 | 0.546 | **FAIL** |
| CDD | −0.0199 | −0.0381 | 0.200 | **FAIL**（且**下降**，违反"CDD 不降"） |

**→ 四域一致未通过。拒绝"对称共性上下文带来独立增益"这一 gate 假设，不新增第四专家。**
按方案 §11.1 第 6 步："如果 S2 未独立优于 S1，拒绝该创新；**不要改个模块名继续堆叠**。"

**判读要点**：

- 两个域（SYSU 0.72τ、LEVIR 0.71τ）呈现**同向但未达阈值**的正向信号；
  另两个域（WHU 0.01τ、CDD −0.10τ）**完全没有反应**。
  → 这是"**在噪声尺度内、跨域不一致**"的典型图样，不是"小而一致的效应"。
- **CDD 上 S2 < S1**，直接违反 gate 里写明的"CDD 不降"。
- 机制层面：S2 的主张是 `m_s`/`v_s` 帮助 gate 区分伪变化；WHU 正是伪变化值得处理的域之一，
  却零反应——这与该主张不符。

## 5. 允许的结论与不允许的结论

**可以说：**

1. **Gate R2 未通过**（0/4 域超过各自的 τ），按预注册规则拒绝 S-PCG 作为独立机制创新。
2. `S2−S1` 在四域上均值 +0.338pp，**没有任何一个域超过其噪声阈值**；
   SYSU（+0.967，0.72τ）与 LEVIR（+0.390，0.71τ）是其中最大的两个，可列为**待复核观察**。
3. `S2 ≥ S0` 在四域都成立但幅度 ≤+0.43pp——同样在噪声尺度内，**不构成已验证的增益**。
4. 部署侧完全一致：12 个 run 的 Infer Params 3.2803–3.3132M、FLOPs 3.2432–3.2433G、
   swap/deploy error 全为 0，因此上述差值**不能**归因于容量或几何一致性差异。

**不可以说：**

- ❌ "S-PCG 有效" 或 "S-PCG 无效/有害" —— 前者超不过 τ，后者也没有证据（CDD 的 −0.02pp 远小于 τ=0.20）。
- ❌ "对称共性上下文能识别伪变化" —— 这正是被 WHU 零反应反驳的机制主张。
- ❌ "S2 已超过旧 C1" —— 跨批次比较无效：本次同配置 S0-C1（SYSU 83.14）本身就比历史 C1（82.57）高 0.57pp。
- ❌ "硬目标可达" —— 即使按 SYSU 上最大的 +0.97pp 外推，83.33 + 0.97 = **84.30 < 85**。
