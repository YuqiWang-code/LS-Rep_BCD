## 3. Gate R1 判定：**失败**

预注册 Gate R1（`train_scripts/CATA-CD/Run2/README.md` 顶部）：

> `J1-TASKKD` 相对 `J1-GATE`（同辅助头容量、同训练预算、同区域 G、同数据流，仅软目标不同）
> 的 SYSU test **ΔF1 必须 > 0.82pp** 且 ΔIoU 同向。

实测 **ΔF1 = −0.1813pp、ΔIoU = −0.2621pp** → **未达门槛，且方向为负。**

对应方案 §4.4 判决分支：
> 可复现 / J1-GT 相对 C1 为正 / J1-GATE 相对 GT 为正 / J1-TASKKD 相对 GATE ≤ 0
> → **teacher 只提供了可靠区域*筛样*，soft representation 无独立价值；
> 可写训练期筛选机制，不再称知识蒸馏主创新。**

## 4. 允许的结论与不允许的结论

**可以说：**

1. 在 SYSU、本协议、单教师（dinov3_lvd）、单次运行下，把一个**GT-only 1 通道辅助头**
   加在 c2 上，test F1 **+0.47pp / IoU +0.67pp**。
2. 把该辅助头的监督**限制在"教师与 GT 一致且排除 2px 边界带"的区域**，再 **+0.17pp / +0.25pp**。
3. **把 target 从硬 GT 换成教师的软响应 `q_T`，收益为负（−0.18pp / −0.26pp）**，
   且 `J1-TASKKD ≈ J1-GT`（−0.01pp）：**教师软目标的独立信息量在本设置下为零**。
4. 四条 run 的部署侧完全一致（3.2803M、3.2432G、swap/deploy error 0），
   所以上述差值**不能**归因于部署容量或几何一致性差异。

**不可以说：**

- ❌ "教师知识对轻量学生无价值" —— 本实验只检验了**一种**转译方式（1ch 任务对齐软目标），
  且只在一个数据集、一个教师上。
- ❌ "GT 辅助头 +0.47pp 已被证明有效" —— 该幅度 **低于 SYSU 的工程噪声阈值 τ=0.82pp**，
  且 J0 已证明训练是混沌的（同配置 187 步后 loss 差可达 4.6e−2）。
  这只是**单次抽样点估计**，属于"值得优先复核的观察"，不是已确立的效应。
- ❌ "−0.18pp 证明软目标有害" —— 同样在噪声尺度内，只能说明**未观察到正增益**。
- ❌ "教师选择/main line 已死" —— 本结果否定的是**原始 128ch cosine KD 与 1ch 软目标转译**，
  不是"所有蒸馏机制"。

## 5. 与校准诊断的一致性

`audit_taskkd`（train-only，512 样本）给出的 SYSU/dinov3_lvd 诊断：

| 量 | 值 |
|---|---|
| balanced AUROC(q_T, GT) | 0.8523 |
| changed recall @`t_plus` | 0.5173 |
| **unchanged leakage @`t_plus`** | **0.0962** |
| AUROC boundary / interior | **0.533 / 0.861** |
| ECE raw → affine refit | 0.3423 → 0.0640 |

`t_plus (0.6412) ≤ t_minus (0.6462)`：教师响应在变化/未变化之间**几乎没有分离**。
被 `G` 保留的正样本只有约 51.7% 的真变化像素，且**边界带上 AUROC≈随机**（0.533）。
这与"把软目标换成 `q_T` 没有正收益"在机制上自洽：**该 `q_T` 能提供的信息基本已被硬 GT 覆盖，
而在它唯一可能额外有价值的地方（边界、伪变化）它本身接近无信息。**
