### 2.3 当前 Agent（A-LODO）的完整定义

- **State**：`x(D,T) = [s_D, c(D,T)]`
  - `s_D`：17 维手工 dataset signature（change ratio、连通分量数、面积分位、小/大目标占比、boundary/area、compactness、RGB mean/std shift、hist JS、edge disagreement、grad diff、低/高频差、unchanged 区光度差）
  - `c(D,T)`：5 维 train-only teacher probe（`change_mean`、`unchanged_mean`、`ratio`、`conf_change`、`conf_unchanged`），由 cache 的 `local_change`/`confidence` 与 label 在 train split 上算
  - 共 22 维（**尚未纳入任何 teacher metadata embedding**）
- **Action**：`{9 个 Teacher Package} ∪ {None}`，**hard selection**（不做多教师混合、不做互促）
- **Reward**：`r = ΔF1_val + 0.5·ΔIoU_val`（相对 C1）；**test 绝不参与训练或选择**
- **Policy**：tiny MLP（22→96→32→1），输入与目标均标准化，MSE 拟合
- **None 判定**：若最大预测分 ≤ 0 则选 None
- **验证**：Leave-One-Dataset-Out（4 折），每折用其余 3 个数据集训练、在留出数据集上选择

### 2.4 Agent 的 LODO 结果（val 效用，pp）

| 数据集 | oracle-val | A-LODO(MLP) | A-LODO(ridge) | A-F 固定教师 | A-H 启发式 |
|---|---|---|---|---|---|
| SYSU | None | **None ✓** (0.000) | **None ✓** | anysat (−1.837) | sam2 (−0.535) |
| WHU | anysat (+0.221) | None ✗ (gap 0.221) | None ✗ | dinov3_lvd (−0.589) | sam2 (−0.641) |
| CDD | None | dinov3_lvd ✗ (gap 0.093) | sam2 ✗ (0.002) | mars (−0.036) | sam2 (−0.002) |
| LEVIR | anysat (+0.270) | **anysat ✓** (0.000) | sam2 ✗ | mars (+0.177) | sam2 (−0.165) |

→ 2/4 fold 精确一致，3/4 fold gap ≤0.20pp（WHU 0.221 略超）；**明显优于 A-F / A-H 基线**；从不选有害教师。

### 2.5 M1（按 Agent 选择从头重训，不复用任何 checkpoint）

|---|---|---:|---:|---:|
| SYSU | None | 82.76 | 82.57 | +0.19 |

### 2.6 ⚠️ 最重要的发现：单 seed 结果不可复现，噪声 > 效应

M1/SYSU 与 M1/WHU 的配置与 C1 **逐字段完全相同**（dca_mode、teacher_package=none、seed、batch、steps、预训练权重全同），但结果差 **+0.19 / −1.03 pp F1**；训练曲线**从第 0 个 epoch 就分叉**（SYSU epoch0 loss 3.5051 vs 3.4897，WHU 5.2305 vs 5.2067）。WHU 上"同配置"run 的 test F1 散布达 **1.9pp**（92.66 … 94.60）。

怀疑来源：① LWGANet 用 `nn.SyncBatchNorm`（backward 归约 atomic 求和非确定）；② 原始 C1 以 **3-way 并发**运行、M1 以 **2-way** 运行，并发度变化可能影响 cuBLAS/cuDNN 算法选择；③ best-val checkpoint 选择把微小数值差放大成不同 checkpoint。

### 2.7 噪声底实验结果（已完成：C1 配置在四数据集各重复 R1/R2/R3，共 12 run，全部与 C1 同为 3-way 并发）

| 数据集 | C1 | R1 | R2 | R3 | M1(同配置但 2-way) | **σ_3way** | 极差 |
|---|---:|---:|---:|---:|---:|---:|---:|
| SYSU | 82.57 | 82.22 | 82.91 | 82.42 | 82.76 | **0.289** | 0.684 |
| WHU | 94.04 | 94.64 | 93.42 | 93.63 | 93.01 | **0.537** | 1.220 |
| CDD | 97.75 | 97.75 | 97.76 | 97.73 | 97.74 | **0.013** | 0.031 |
| LEVIR | 91.04 | 90.69 | 91.13 | 91.07 | 90.99 | **0.195** | 0.432 |

- 平均 σ_3way = **0.259pp**；σ_mixed（并入 2-way 的 M1 后）WHU 升到 0.623、其余几乎不变 → **并发度不是主因，内在 run-to-run 噪声本身在 WHU 上就很大**。
- **σ 强烈数据集相关**：CDD 稳定到 0.013pp，WHU 高达 0.537pp（WHU 测试集仅 744 张）。

### 2.8 用 σ 重新判读效应（效应/σ）

| 效应 | ΔF1 | σ | 倍数 | 判读 |
|---|---:|---:|---:|---|
| DCA→WHU（C1−C0） | +1.38 | 0.537 | **2.6σ** | 接近显著 |
| RADIO→SYSU | +0.68 | 0.289 | **2.4σ** | 接近显著 |
| DCA→SYSU | +0.44 | 0.289 | 1.5σ | 不显著 |
| MARS→WHU | +0.56 | 0.537 | 1.0σ | **不显著（实为噪声）** |
| UNISAT→WHU | +0.40 | 0.537 | 0.7σ | 不显著 |
| D3S→LEVIR | +0.14 | 0.195 | 0.7σ | 不显著 |
| CDD 全部教师 | ≈0 | 0.013 | ~0 | 确认真无效应 |

**关键修正**：并不是"一切皆噪声"。**SYSU 的 RADIO 效应与 DCA 在 WHU/SYSU 的效应超出噪声**；而 **WHU 上的全部教师效应都在噪声内**（之前看到的 MARS→WHU +0.56 是假象）。也就是说「教师是否有效」这个问题**部分可测、部分不可测，且可测性依赖数据集**。注意 σ 由 3–4 个样本估计，自身不确定性很大。

## 三、我的问题诊断（欢迎你纠正）

1. **数据量根本不够**：4 数据集 × 9 教师 = 36 个 (state, reward) 对；LODO 后每折只有 27 个训练样本 → 任何策略都难以学出可泛化映射。
2. **监督信号本身不可靠**：val 效用与 test 效用明显不一致，且 val 效用数值极小（多为 ±0.1pp 量级），接近数值噪声。
3. **噪声与效应同量级且随数据集变化**：实测 σ ∈ [0.013, 0.537]pp（平均 0.259pp）。教师最强效应 +0.68pp 在 SYSU 上约 2.4σ（接近显著），但在 WHU 上 +0.56pp 仅 1.0σ（纯噪声）。→ 问题不是"完全不可学"，而是**"哪些可学"依数据集而定**，且 Agent 必须在**不知道 σ 的数据集上**判断"该不该出手"。这是当前 Agent 完全没建模的部分。
4. **probe 太弱**：仅 5 维、且与「教师能力」的因果关联未经证明。
5. **None 阈值语义不清**：标准化目标下用「预测分 ≤0」当阈值，等价于预测"优于训练集平均"，而不是"优于 C1（baseline）"。
6. **state 缺少教师侧信息**：没有 teacher metadata embedding（模型族、预训练域、原生 stride、是否 dense global、参数量等），而不同教师的知识类型差异极大。
