## 一、不变的任务与硬约束（背景）

- **项目**：LS-Rep_BCD（GitHub：https://github.com/YuqiWang-code/LS-Rep_BCD ，可访问其 README 与 docs/ 获取历史实验、协议与代码上下文）。
- **任务**：推理时**极轻量化**的遥感图像**全监督二值变化检测**（不涉及半监督、多类变化、语义分割）。
- **数据集（固定 4 个，256×256）**：SYSU-CD、LEVIR-CD、WHU-CD、CDD-CD。变化特性差异大：SYSU 变化像素占比高（约 21%）、场景复杂；WHU 中等；CDD/LEVIR 变化目标小、占比极低（稀疏小目标）。以上占比仅为提示，请以数据集实际统计为准，勿直接当作结论。
- **最终硬目标（必须同时全部达到）**：
  - 四数据集 F1：SYSU ≥ 85、LEVIR ≥ 92.5、WHU ≥ 95、CDD ≥ 98；
  - IoU 与 F1 同方向；
  - **有效推理参数 < 5M**。
- **研究定位**：服务于 211 高校硕士的学术论文，最高优先级是「网络结构、二时相特征表征与交互、训练期辅助机制及其可解释性」；损失/学习率只用于公平验证，不把调参包装成创新；每项主张需给机制动机、与既有工作的实质区别、可证伪假设、最小消融、失败判据。
- **从头训练纪律**：主实验与全部消融一律从头训练（同一 ImageNet 预训练 + 固定 seed，完整 40K steps），禁止用任何已有 checkpoint 微调/续训作为实验组；目的是证明模块本身有效性（唯一变量：C0 干净对照 + M1 主实验），不是工程化堆 SOTA。
- **环境**（供你评估算力/可行性）：RTX 5090 ×2（Blackwell/sm_120）、PyTorch 2.14.0+cu132、CUDA 13.2。

## 二、为什么换主线（历史教训）

此前走「方向 C 教师/蒸馏」整条线：RDT-CD → SCTC → FA-SCRD → SAGE-CD Run1/Run2，核心都是「用一个/两个大模型（DINOv3、SAM2 等）做教师，做固定蒸馏 / 联合蒸馏 / 互相促进 / 教师-学生互相挑选或路由」。多次实验高度数据集不一致：同一教师对不同数据集增益方向相反（如 DINOv3 语义教师只帮低变化 WHU、伤高变化 SYSU；SAGE-CD Run2 主方法 R4−R2 = SYSU −0.44 / WHU +0.18，主门失败）。因此决定**放弃「一两个大模型做教师 + 联合/互促/互选」路线**。

## 三、新主线（我的初步假设，需你验证与纠偏）

做一个**数据集自适应教师 Cache 选择 agent/路由**：

1. **按数据集特征选择教师 Cache**：例如变化场景多且复杂的数据集 → 适合用 SAM2 分割类 Cache 做教师；变化目标小、占比低的数据集 → 适合 DINOv3 语义类 Cache；同时还要调研 CLIP 等其它大模型。目前「用哪些特征、定什么判据」只是我的猜测，需要实验分析来定义。
2. **每个大模型的教师 Cache 配一个「专属可学习交互模块」**：用于与学生互相学习、互相挑选、互相促进；且该模块按大模型特性定制（如适配小目标场景的大模型，其交互模块要更精于提取小目标信息）。同样需要调研。

**硬性要求**：所有教师 / Cache / 交互模块只允许训练期使用，**不得进入部署主图**（推理只跑 <5M 的轻量学生）；teacher map/prior 不得注入部署主特征路径。
