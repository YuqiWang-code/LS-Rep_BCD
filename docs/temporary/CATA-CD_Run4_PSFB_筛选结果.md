## 3. 判定：**部分通过，且这是本项目第一次**

报告的预注册条件有两项：

| 条件 | 实测 | 判定 |
|---|---|---|
| `REAL−ZERO ≥ +1.00pp` 且 IoU 同向 | +0.2972 / +0.5008 | **FAIL** |
| `REAL−SHUFFLE > +0.546pp` | **+0.6214 / +1.0440** | **PASS（首次）** |

**这是三轮以来第一个超过 LEVIR 噪声尺度的配对特异性效应**：正确配对的教师证据比同 batch 错配
好 **+0.62pp F1 / +1.04pp IoU**，且去掉 64 通道特征直传会损失 **+0.47pp**。

**但必须同时报告一个反向事实**：`SHUFFLE−ZERO = −0.3242pp`——**错配教师比完全没有教师更差**。
因此 `REAL` 相对 `SHUFFLE` 的优势中，有约 0.32pp 只是"挽回自己造成的损失"，**净增益仍只有 +0.30pp**。

> 准确的表述是：**该桥接机制是"条件性有价值"的**——一旦装上这个 bridge，就必须喂正确配对的教师，
> 否则比不装更差；但相对"不装教师"的净收益仍然小（+0.30pp，未过 +1.0pp）。

## 5. 机制诊断：桥接会**自我熄灭**

`H = C3 + α·Δ`，影子 Decoder 与主 Decoder 共享权重。把 `Δ` 压到 0（`H_T → C3`）是同时降低
`L_shadow`（影子前向退化为已训练好的主前向）与 `L_feat`（两个视图一起塌）的**最省力解**，于是
训练**主动关闭教师通路**。终值 `|Δ|`：

| 模式 | `\|Δ_T\|` 终值 | 相对初始（≈0.84） |
|---|---:|---:|
| REAL（D3S / D2 / RAD） | 0.105 / 0.103 / 0.113 | **≈1/8** |
| ZERO（D3S / D2 / RAD） | 0.0051 / 0.0044 / 0.0045 | **≈1/170** |
| SHUFFLE（D3S） | 0.0068 | ≈1/124 |
| NOFEAT（D3S，λ_f=0） | 0.0335 | ≈1/25 |

`D4-L-D3S-R` 的 `‖HT−H0‖` 逐 epoch 单调衰减 10 倍：0.278 → 0.145 → 0.088 → … → **0.026**。

**两点可写进论文的机制结论**：
1. **所有模式下残差都向 0 衰减**；`ZERO`/`SHUFFLE` 几乎完全关死（≈0.005），
   **只有 `REAL` 保留约 0.10——教师配对输入是唯一让该通路存活的因素**；
2. 这解释了为什么净效应只有 +0.30pp：**通路在训练中被自己关掉了**，
   而不是"教师信息不足"或"梯度传导不到"。

## 7. 允许的结论 / 不允许的结论

**可以说：**

1. LEVIR 上 `D3S REAL−SHUFFLE = +0.6214pp F1 / +1.0440pp IoU`，**超过预注册的 0.546pp 配对特异性门槛**；
   去掉 64 通道特征直传损失 `+0.4695pp` ⇒ **正确配对的教师信息确实被使用了**。
2. `SHUFFLE−ZERO = −0.3242pp` ⇒ 该 bridge **在错配输入下比不装更差**，是条件性机制而非免费正则。
3. 三个教师 `REAL−ZERO` 跨度 **0.1043pp**（< 0.546）⇒ **教师不可区辨，Agent 仍无信号**（第三次独立确认，且无初始化混杂）。
4. 桥接残差在训练中衰减 8–170 倍 ⇒ **通路自我熄灭**，这是净效应小的机制解释。
5. CDD 上 `REAL−ZERO = −0.0492pp`（<0.20 地板）⇒ 近饱和域未检出。
6. 部署侧完全一致（3.2803M / 3.2432G / swap·deploy 0）⇒ 差值不能归因于容量或几何一致性。

**不可以说：**

- ❌ "PSFB 有效（≥1pp）" —— `REAL−ZERO` 只有 +0.2972pp，**未过预注册的 +1.00pp**。
- ❌ "PSFB 无效" —— `REAL−SHUFFLE` 与 `REAL−NOFEAT` 都**超过了单差噪声尺度**，不能声称无效应。
- ❌ "教师无用/蒸馏普遍无效" —— 本轮恰恰**首次**检出了超过噪声的配对特异性效应。
- ❌ "教师可区辨、Agent 有信号了" —— 跨度 0.1043pp，**恰恰相反**。
- ❌ "REAL 比 ZERO 好 0.30pp 就是净收益" —— 其中约 0.32pp 是对"错配更差"的挽回；
  净收益应按 `REAL−ZERO` 读，且它未过门槛。
- ❌ 用跨轮次绝对 F1 比较说"PSFB 超过 CTP/v2" —— 三者极差 0.032pp < σ/6，无统计意义。
