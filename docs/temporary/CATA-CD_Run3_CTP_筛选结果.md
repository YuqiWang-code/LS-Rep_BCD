## 4. **最关键的一条：绝对水平没有提升**

把新旧通道在同一教师、同一数据集上做**绝对**对比（这是最不容易被 CTRL 漂移误导的口径）：

| 口径 | LEVIR F1 |
|---|---:|
| **旧通道**（v2：固定随机投影 → 128ch 单尺度 cosine KD）最好教师 dinov3_sat | **91.1732** |
| **新通道**（v3：多通道 E/M + 训练期特权评论器 + 反事实控制）最好教师 dinov3_sat | **91.1707** |
| **绝对差** | **−0.0025 pp** |

| 新 CTRL（`C3L-Z` zero） | 90.8685 |
| CTRL 漂移 | **−0.1715 pp** |

**结论**：彻底替换整个知识通道（表征形式、投影方式、监督目标、注入位置、是否有教师输入）
之后，**最好成绩与旧通道相差 0.0025pp**。相对增益从 +0.14pp 变成 +0.30pp，
**几乎全部来自 CTRL 下移 0.17pp**，而不是绝对水平上升。

> ⚠️ 因此"新通道把效应翻倍"这类说法**不成立**；正确表述是
> "**新通道在 LEVIR 上未观察到绝对提升；相对增益的变化可由 CTRL 漂移解释**"。

## 5. 允许的结论 / 不允许的结论

**可以说：**

1. 在 LEVIR、本协议、单次运行下，`REAL(dinov3_sat) − ZERO = +0.302pp F1 / +0.509pp IoU`，
   方向为正、IoU 同向，但**仅 0.55τ，未达预注册的 +1.0pp**。
2. **配对关系本身的贡献只有 `REAL − SHUFFLE = +0.135pp`**：把教师证据换成**同 batch 内别的样本**，
   仍能拿到约 45% 的增益 ⇒ **该增益的主要部分并非来自"教师与图像的正确配对"**。
3. **三个教师在 LEVIR 上的跨度只有 0.30pp（0.55τ），在 CDD 上只有 0.002pp（0.01τ）**
   ⇒ 经本通道，**不同教师之间仍不可区辨**，选师 Agent 依然缺少可选的信号。
4. **绝对水平无提升**：新通道最好 91.1707 vs 旧通道最好 91.1732（−0.0025pp）。
5. 部署侧完全一致（3.2803M / 3.2432G / swap·deploy error 0），差值不能归因于容量或几何一致性。

**不可以说：**

- ❌ "CTP-Critic 有效" —— +0.302pp 未达预注册阈值，且绝对水平未提升。
- ❌ "CTP-Critic 无效/有害" —— CDD 的 −0.009pp 远小于 τ=0.20；LEVIR 的 +0.302pp 也**不能**证明效应为零。
- ❌ "教师配对知识不重要，所以教师无关" —— `REAL−SHUFFLE` 仅 +0.135pp 说明**在这一个教师、一个域上**
  配对贡献很小；这是单次观察，且 `< τ`。
- ❌ "新通道让教师可区分了" —— 恰恰相反：跨度 0.30pp/0.002pp 仍远小于阈值。
- ❌ 用跨批次比较说"S2/新通道超过了旧 C1" —— 新 CTRL 本身就比旧 C1 低 0.17pp。
